# Design-and-Analysis-of-Algorithms-
This repository contains C language implementations of fundamental data structures and algorithms, spanning sorting, searching, dynamic programming, greedy methods, computational geometry, and graph theory.

File Name	                    - Category                   - Description
Convex_Hull / Convex_hull.    - Computational Geometry     - Computes the smallest convex polygon enclosing a given set of 2D points. 
  
Fibonacci_series              - Dynamic Programming / Math - Calculates terms of the Fibonacci sequence with execution timing measurement. 

Fractional_knapsack         	- Greedy Algorithm	         - Solves the Fractional Knapsack problem using a greedy approach to maximize value.  

Hello                       	- Basics	                   - Basic environment verification program printing standard output.  

Insertion_sort               	- Sorting	                   - Implements the O(n^2) Insertion Sort algorithm for small datasets or nearly sorted arrays. 

Knapsack_problem             	- Dynamic Programming	       - Solves the 0/1 Knapsack problem using dynamic programming to optimize capacity.  

Linear_Search               	- Searching	                 - Sequential iterative search algorithm to locate an element in an array. 

Linear_recursive             	- Searching	                 - Recursive variant of the linear search algorithm. 

Longest_common_subsequence  	- Dynamic Programming	       - Finds the longest subsequence common to two sequences.  

MST_Dijkstra_alg	            - Graph Theory	             - Implements Dijkstra's algorithm to find the shortest path from a source node. 

MST_Krushkals	                - Graph Theory	             - Implements Kruskal's algorithm using Disjoint Set Union (DSU) for Minimum Spanning Trees. 

Max_and_min	                  - Divide & Conquer / Math	   - Finds the maximum and minimum elements in an array with timing benchmarks. 

Merge_sort	                  - Sorting	                   - Implements the O(nlogn) Divide and Conquer Merge Sort algorithm. 

Miller_rabin	                - Number Theory	             - Probabilistic primality test to determine if a given number is prime.  

N-Queens	                    - Backtracking	             - Solves the N-Queens puzzle placing N non-attacking queens on an N×N chessboard. 

Quick_sort	                  - Sorting	                   - Efficient O(nlogn) in-place partitioning sort algorithm. 

Subset_backtracking	          - Backtracking	             - Finds subsets of a given set whose elements sum to a targeted value.
